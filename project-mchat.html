MChat.

A private AI chat app for Mac that runs entirely on-device and answers from my own notes and documents, with cited sources.

Role
Solo Developer
Platform
macOS (native app)
Model
Apple on-device LLM
Tech
Swift · SwiftUI · SwiftData

The problem

Every new Mac ships with a capable AI model that runs privately on the device, but the only built-in way to talk to it was a Terminal window. The model is also small: its memory holds about 8,000 tokens, so it starts forgetting after roughly ten messages, and it knows nothing about my own notes.

What I built

  • A native Mac chat app in SwiftUI with Apple's Liquid Glass design, streaming replies, and saved, searchable conversations.
  • Retrieval over my Obsidian notes: instead of loading everything into the model, the app searches the notes and sends only the few most relevant passages with each question.
  • Hybrid search that combines keyword scoring (TF-IDF) with on-device semantic embeddings, so both exact terms and synonyms match.
  • An incremental index cached to disk, so only new or edited notes are re-processed, in the background.
  • Drag-and-drop PDF, Word, and text files into a chat and ask questions about them.
  • A live memory meter, plus automatic recovery when the model's memory fills up.

Why it's built this way

Everything stays on the Mac: no cloud calls, no accounts, no telemetry. Every answer lists the notes or files it came from, and the exact prompt and retrieval scores are logged, so any answer can be traced back to its sources. I deliberately left out Apple's larger cloud model rather than let the app send data off-device without asking.

What I learned

A small model is only as good as what you feed it. Most of the work was in retrieval and context management, not the chat itself. Being explicit with the model, and showing users its limits instead of hiding them, made a bigger difference than any single feature.
